# MVP Roadmap — AfraKala Django ERP

## هدف MVP

ساخت کوچک‌ترین نسخه‌ای که واقعاً برای افراکالا ارزش عملیاتی دارد؛ نه یک ERP نمایشی.

مسیر اصلی MVP:

کالا → قیمت خرید → نرخ ارز → محاسبه قیمت فروش → خروجی لیست قیمت → لاگ تغییرات → داشبورد ساده مدیر

## فاز 0 — پایه‌گذاری ریپو

- README
- مستندات Source of Truth
- مستندات معماری
- مستندات نیازمندی‌ها
- قرارداد API ربات‌ها
- اسکلت Django

## فاز 1 — مدل‌های پایه

- Brand
- Category
- Product
- Supplier
- ExchangeRate
- PricingRule
- ProductPrice
- PriceChangeLog
- BotApiKey
- BotRequestLog

## فاز 2 — پنل مدیریت

- ورود کالاها از Django Admin
- ورود نرخ ارز
- ورود قیمت خرید
- مشاهده تاریخچه قیمت
- فیلتر بر اساس برند، دسته و وضعیت کالا

## فاز 3 — API اولیه

- API خواندن محصولات برای ربات
- pagination
- authentication با bot API key
- پاسخ‌های JSON استاندارد برای 401/403/200
- audit log درخواست‌های ربات

## فاز 4 — خروجی لیست قیمت

- خروجی JSON
- خروجی CSV
- خروجی PDF در فاز بعد
- آماده‌سازی برای ارسال به کانال‌های فروش

## فاز 5 — داشبورد مدیریتی ساده

- تعداد کالاهای فعال
- آخرین تغییرات قیمت
- کالاهای بدون قیمت
- تغییرات نرخ ارز
- هشدارهای مهم

## فازهای بعدی

- CRM و مشتریان B2B
- سفارش و پیش‌فاکتور
- اتصال به CRM دیدار
- هوش مصنوعی فروش
- تحلیل ریسک دلار
- اتصال به ربات‌های استخراج لید و ترب
- dynamic tables شبیه Google Sheets

## معیار موفقیت MVP

MVP وقتی موفق است که مدیر بتواند با داده واقعی افراکالا:

1. کالا ثبت کند.
2. قیمت خرید و نرخ ارز ثبت کند.
3. قیمت فروش قابل ردیابی بگیرد.
4. تغییرات قیمت را ببیند.
5. ربات بتواند لیست کالا/قیمت را از API بخواند.
