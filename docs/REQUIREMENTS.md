# Requirements — AfraKala Django ERP

## نیازهای اصلی کسب‌وکار

افراکالا در فروش B2B لوازم خانگی فعالیت می‌کند. نیاز اصلی، کاهش خطای انسانی، کنترل قیمت، سرعت در فروش، و تصمیم‌گیری بهتر روی موجودی، قیمت و ریسک ارز است.

## نیازهای پوشش داده‌شده در طراحی

### 1. لیست قیمت هوشمند

- ثبت کالا، برند، مدل، دسته‌بندی و ویژگی‌ها
- ثبت قیمت خرید
- ثبت قیمت فروش
- محاسبه قیمت فروش با نرخ ارز، سود، کرایه و قانون دسته کالا
- خروجی لیست قیمت برای فروش
- خروجی PDF در فاز بعد
- لاگ تغییر قیمت
- مشاهده قیمت قبلی و درصد تغییر

### 2. مدیریت قیمت و ارز

- نگهداری نرخ ارز مرجع
- امکان ثبت چند منبع نرخ ارز در آینده
- تشخیص تغییرات مهم قیمت
- هشدار برای نوسان شدید
- امکان تحلیل ریسک فروش تومانی در برابر رشد دلار

### 3. داشبورد مدیریتی

- KPI فروش روز
- سفارش‌های جدید
- مشتری‌های جدید
- سود خالص
- فعالیت‌های اخیر
- وظایف و هشدارها
- UI فارسی RTL و mobile drawer

### 4. فروش و CRM

- ثبت مشتری B2B
- ثبت سفارش/پیش‌فاکتور
- پیگیری مشتری
- تحلیل تیپ مشتری در فاز بعد
- اتصال احتمالی به CRM دیدار در فاز بعد

### 5. مالی و تسویه

- ثبت روش تسویه
- اثر تسویه بر سود
- ثبت پرداخت‌ها در فاز بعد
- گزارش سود و ریسک در فاز بعد

### 6. ربات‌ها و کارخانه داده

ربات‌های تعریف‌شده در پروژه:

- استخراج لید
- استعلام‌گیر
- آپدیت قیمت
- نرخ دلار
- گزارش‌گذار ترب
- تمیزکننده شبانه
- استخراج لید از سایت‌های مشابه ترب
- تبدیل صوت به متن روبیکا

این ربات‌ها باید داده را از طریق API کنترل‌شده بخوانند/بنویسند.

### 7. جداول پویا

در وب‌اپ دستیار هوشمند افراکالا، جداول پویا باید شبیه Google Sheets باشند؛ قابل خواندن و نوشتن توسط ربات‌ها، اما با کنترل دسترسی، لاگ و اعتبارسنجی.

## نیازهای غیرعملکردی

- فارسی و RTL-first
- طراحی enterprise-grade و ساده
- API-first
- لاگ‌پذیر و قابل audit
- جداسازی محیط توسعه و تولید
- عدم ذخیره secret در مخزن
- ساختار ماژولار برای توسعه تدریجی

## اولویت‌های فاز اول

1. اسکلت Django
2. مدل‌های پایه catalog/pricing/bots
3. API خواندن لیست کالا برای ربات
4. پنل مدیریت Django برای ورود داده اولیه
5. لاگ تغییر قیمت
6. مستندات API
