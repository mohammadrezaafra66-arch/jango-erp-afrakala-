# AfraKala Django ERP

این مخزن، ریپوی مرجع برای انتقال پروژه‌ی «دستیار هوشمند افراکالا / دستیار جنگجو پایتون افراکالا» به یک اسکلت اجرایی Django است.

> وضعیت فعلی: ریپو تازه initialize شده و انتقال اولیه در branch جداگانه انجام می‌شود.

## هدف پروژه

ساخت یک پلتفرم عملیاتی برای فروش B2B لوازم خانگی افراکالا؛ با تمرکز روی:

- مدیریت کالا، برند، دسته‌بندی و تأمین‌کننده
- لیست قیمت هوشمند و تاریخچه تغییر قیمت
- قیمت‌گذاری بر اساس نرخ ارز، سود، کرایه، تسویه و قوانین خاص کالا
- داشبورد مدیریتی فارسی RTL
- اتصال به ربات‌ها و کارخانه داده‌ی تمیز
- فروش، مالی، تحلیل، CRM و دستیار تصمیم‌یار

## مرجع‌های اصلی

مستندات پروژه در مسیر `docs/` نگهداری می‌شوند. مهم‌ترین فایل‌ها:

- `docs/SOURCE_OF_TRUTH.md`
- `docs/ARCHITECTURE.md`
- `docs/REQUIREMENTS.md`
- `docs/BOT_API_CONTRACT.md`
- `docs/MVP_ROADMAP.md`

## هشدار اجرایی

این پروژه هنوز ERP کامل آماده تولید نیست. این انتقال، مرحله‌ی پایه‌گذاری ریپو، معماری، قراردادها و اسکلت Django است. اولویت فنی فعلی: MVP لیست قیمت هوشمند.
